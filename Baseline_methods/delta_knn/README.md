# Delta-KNN Baseline

This directory contains the MRI-adapted implementation of Delta-KNN used in this study.

The implementation was adapted from the original Delta-KNN code released by the method authors. The original method was designed for text-based Alzheimer's disease classification and used document embeddings for nearest-neighbour selection.

## Adaptations for this study

To apply Delta-KNN to MRI-derived tabular features, the implementation was modified to:

- operate on MRI-derived regional volume and cortical thickness features rather than text;
- use standardized MRI feature vectors with cosine similarity for KNN representative selection;
- use AD and CN diagnostic labels;
- construct the Delta matrix using the MRI-specific LLM prompts used in this study;
- use the fixed training and test splits generated by the study pipeline;
- select an equal number of AD and CN demonstrations.

The core Delta-KNN procedure is retained:

1. Identify the `k` nearest training subjects for each test subject.
2. Use those subjects as representative columns of the Delta matrix.
3. Compute the mean Delta score for each candidate demonstration.
4. Rank candidate demonstrations by mean Delta.
5. Select the highest-ranked balanced AD and CN examples.

## Files

- `deltaknn.py` — Delta-KNN example-selection logic.
- `calculate_knn.py` — KNN representative selection using standardized MRI features.
- `calculate_delta_matrix.py` — construction, checkpointing, averaging, and loading of the Delta matrix.
- `build_delta_matrix.py` — optional utility for precomputing the Delta matrix.
